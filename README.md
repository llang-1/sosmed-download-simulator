## ⚡ Sosmed Download Simulator

This project is a simulation of a **Social Media Downloader**, built using Laravel.  
Users can "simulate" downloading content from popular social media platforms (e.g. YouTube, TikTok, Instagram) without actually doing it — useful for educational, UI/UX testing, or system flow demonstrations.

### Features

- Simulated media links (not actual downloads)
- Fake download progress animation
- Clean and responsive UI (Tailwind CSS)
- Log system to track simulated downloads
- Built with Laravel for easy extension and routing

> ⚠️ Note: This project is for educational/demo purposes only. It does not violate any terms of service since it does **not** perform real downloads.
